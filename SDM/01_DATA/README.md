# Data directory (`01_DATA/`)

## Overview

The `01_DATA/` directory contains input datasets, spatial reference data and intermediate files used in the R workflow for species distribution modeling and mapping in the Eastern and Western English Channel.

**The complete contents of this directory are not included in the repository.** Running the full workflow (`00_SOURCE.R`) requires the missing input datasets and any intermediate files expected by the scripts.

## Data organisation

### 1. Spatial data (`shapefiles/`)

Contains spatial study area boundaries derived from the **World Seas IHO v3 shapefile**, available from [Marine Regions](https://www.marineregions.org/downloads.php#iho) (download link also provided in `04_MODEL/functions/create_study_area_shapefile.R`).

The script `create_study_area_shapefile.R` is run independently to delineate the Eastern and Western English Channel domains. The Western English Channel boundary is extended into the Celtic Sea to encompass the full WCGFS survey area.

The resulting shapefiles are stored in `01_DATA/shapefiles/`, including:

- `split_English_Channel/east_English_Channel.shp`: Eastern English Channel study domain.
- `split_English_Channel/west_English_Channel.shp`: Western English Channel domain before extension.
- `Western_English_Channel_extension/Western_English_Channel_extension.shp`: extended Western English Channel study domain.

The Eastern and extended Western boundaries are subsequently used for spatial mesh construction, prediction grid generation, mapping, exploratory analyses and HTML reporting.

### 2. Groundfish survey data (`surveys/`)

- **`ECGFS/`:** data from Eastern Channel Ground Fish Survey (https://www.seanoe.org/data/00894/100620/)
- **`WCGFS/`:** data from Western Channel Ground Fish Survey (https://www.seanoe.org/data/00896/100818/)

These datasets (catches and operations) contain scientific bottom-trawl survey observations used for species distribution modeling.

### 3. Land boundaries (`ne_10m_land.rds`)

Contains land polygons obtained from the `rnaturalearth` R package and saved locally as an `.rds` file for spatial visualisations (https://cran.r-project.org/web/packages/rnaturalearth/vignettes/rnaturalearth.html).

### 4. Species selection criteria (`species_criteria_region_10percent.rds`)

Contains the species-by-region selection criteria generated by `02_EXPLORE_DATA/species_selection_criteria.R` and loaded by `00_SOURCE.R`.

Contains year-specific spatial fold assignments saved as `.rds` files. These are generated by `04_MODEL/functions/create_folds_blockCV.R` and subsequently used by `04_MODEL/functions/run_block_cross_validation.R` for spatiotemporal block cross-validation.

## Data availability and reproducibility

The repository documents the analytical workflow but does not include the survey datasets. Missing inputs must be provided in the locations expected by the R scripts before running the full pipeline.

For the full modelling workflow and script descriptions, see the main repository `README.md`.
