# Data directory (`01_DATA/`)

## Overview

The `01_DATA/` directory contains input datasets, spatial reference data and intermediate files used in the R workflow for species distribution modelling and mapping in the Eastern and Western English Channel.

**The complete contents of this directory are not included in the repository.** Running the full workflow (`00_SOURCE.R`) requires the missing input datasets and any intermediate files expected by the scripts.

## Data organisation

### 1. Spatial data (`shapefiles/`)

Contains spatial reference data used to define the study area boundaries and support mesh construction, prediction grid generation, mapping and other spatial analyses.

The study area boundaries are generated by running `04_MODEL/functions/create_study_area_shapefile.R` independently once and saving the resulting spatial object as an `.rds` file. This object is subsequently used during mesh construction, prediction grid generation, mapping, exploratory analyses and HTML report generation.

### 2. Groundfish survey data (`surveys/`)

- **ECGFS:** Eastern Channel Groundfish Survey.
- **WCGFS:** Western Channel Groundfish Survey.

These datasets contain scientific bottom-trawl survey observations used for species distribution modelling, spatial predictions and biomass index estimation.

### 3. Land boundaries (`ne_10m_land.rds`)

Contains land polygons obtained from the `rnaturalearth` R package and saved locally as an `.rds` file for spatial visualisations.

### 4. Species selection criteria (`species_criteria_region_10percent.rds`)

Contains the species-by-region selection criteria generated by `02_EXPLORE_DATA/species_selection_criteria.R` and loaded by `00_SOURCE.R`.

The overall occurrence values also determine which likelihood families are considered in `04_MODEL/functions/fit_candidate_models.R`: **lognormal and gamma** at 100% occurrence, and **Tweedie and delta families** otherwise. This overall occurrence measure is distinct from the 10% annual threshold used for regional species selection.

### 5. Cross-validation folds (`folds_CV/`)

Contains year-specific spatial fold assignments saved as `.rds` files. These are generated by `04_MODEL/functions/create_folds_blockCV.R` and subsequently used by `04_MODEL/functions/run_block_cross_validation.R` for spatiotemporal block cross-validation.

## Data availability and reproducibility

The repository documents the analytical workflow but does not include all survey datasets, spatial inputs or intermediate files required to reproduce it. Missing inputs must be provided in the locations expected by the R scripts before running the full pipeline.

For the full modelling workflow and script descriptions, see the main repository `README.md`.
