# Species Distribution Modelling in the English Channel

## Overview

This repository contains a workflow written in R (https://www.r-project.org/) for **species distribution modeling and mapping** using fisheries-independent survey data from the Channel Ground Fish Survey (CGFS) in the Eastern and Western English Channel (https://campagnes.flotteoceanographique.fr/series/11/fr/index.htm).

The workflow uses the `sdmTMB` package (https://sdmtmb.github.io/sdmTMB/articles/index.html) to fit **SPDE-based hierarchical spatiotemporal models** to investigate spatial and spatiotemporal patterns in fish biomass density, generate prediction maps, and estimate biomass indices. 
It also evaluates the influence of model configurations, including SPDE mesh resolution and likelihood formulation, on model goodness-of-fit, predictive performance, and prediction uncertainty.

The workflow is organised around `00_SOURCE.R`, which sequentially executes the following steps:

1. **Initialisation:** install missing R packages, update existing packages, and load all required dependencies using `04_MODEL/packages/packages.R`.
2. **Species and region selection:** choose a species and retrieve its eligible study regions (see **Study area and species selection** section).
3. **Data preparation:** load and transform CGFS survey data.
4. **Preliminary diagnostics:** assess spatial autocorrelation using Moran's I and inspect residuals from fitted models without random fields.
5. **Mesh generation:** construct spatial meshes at several resolutions for the selected regions.
6. **Candidate model fitting:** fit SPDE-based hierarchical spatiotemporal models across mesh configurations and likelihood formulations.
7. **Convergence assessment:** check numerical diagnostics, retain converged models, and extract parameter estimates.
8. **Residual diagnostics:** calculate simulation-based diagnostics using `DHARMa` package (https://cran.r-project.org/web/packages/DHARMa/vignettes/DHARMa.html).
9. **Goodness-of-fit:** calculate conditional AIC (cAIC) and R².
10. **Cross-validation:** perform repeated random cross-validation and spatiotemporal block cross-validation.
11. **Spatial prediction:** create prediction grids, predict from converged models, and generate biomass density maps and bias-corrected biomass indices.
12. **Uncertainty assessment:** compute simulation-based coefficients of variation and produce uncertainty maps.
13. **Reporting:** render a species-specific HTML report from `04_MODEL/report/sdm_report.Rmd`, compiling the results, figures, diagnostics and maps generated during the preceding modelling steps. All previous steps must have been completed, and their output objects must be available in the R environment for the report to be rendered successfully.

At each step, the outputs generated by the sourced scripts are automatically saved in a species-specific, timestamped directory within `05_OUTPUTS`, following the structure:

```text
05_OUTPUTS/<species_name>/<species_name_date_time>/
```



## Study area and species selection

The study covers the Eastern and Western English Channel.

Species were selected according to the study objectives and their occurrence in CGFS surveys, applying a minimum annual occurrence threshold of 10% per region. The selection procedure is documented in `02_EXPLORE_DATA/species_selection_criteria.R`.

The resulting species-by-region criteria are stored in `01_DATA/species_criteria_region_10percent.rds` and automatically loaded by `00_SOURCE.R` to determine which regions are included in the modelling workflow.

The selection table contains the following information:

| Variable | Description |
|---|---|
| `species` | Scientific name of the species. |
| `east_region`, `west_region` | Indicate whether the species meets the regional selection criteria (`TRUE` or `FALSE`). |
| `global_occurrence_east`, `global_occurrence_west` | Overall percentage of survey hauls in which the species was recorded in each region, across all survey years. |

Overall occurrence also determines the candidate likelihood families used in `fit_candidate_models.R`: **lognormal and gamma distributions** are considered when occurrence reaches 100%, whereas **Tweedie and delta distributions** are considered otherwise.

The predefined regional selection can be manually overridden by setting `East_English_Channel` and/or `West_English_Channel` to `TRUE` in `00_SOURCE.R`, provided the required survey data are available. **When manually enabling a region, the corresponding overall occurrence value (`global_occurrence_east` and/or `global_occurrence_west`) must also be specified** to ensure the appropriate candidate likelihood families are selected.

## Modeling functions

The `04_MODEL/functions/` directory contains :

#### Setup and preliminary analyses

| Script | Description |
|---|---|
| `setup_model_outputs.R` | Initializes the output structure for the selected species. Creates a timestamped run directory under `05_OUTPUTS/<species_name>/` to store the `.rds` objects generated at each step of the modeling workflow, together with the final HTML report, without overwriting previous runs. |
| `assess_spatial_autocorrelation.R`  | Computes annual Moran's I for observed biomass density using inverse-distance spatial weights, separately for each study region. Compares observed and expected values under the null hypothesis of spatial randomness, assesses statistical significance, and saves the results and diagnostic plots in a species-specific `.rds` file. |
| `assess_residuals_without_random_fields.R` | Fits preliminary models without spatial and statiotemporal random fields and examines the spatial distribution of their residuals to identify potential spatial patterns not accounted for by the fixed-effects. |
| `create_study_area_shapefile.R` | Run independently once to create and save the study area boundaries as an `.rds` file. These boundaries are used to delineate the inner spatial mesh, define the spatial extent of prediction grids, and provide a geographic reference for mapping model predictions and other spatial results. The saved file is subsequently used in mesh construction, prediction grid generation, mapping, exploratory analyses and report. |
| `simulate_candidate_distributions.R` | Defines functions for simulating candidate statistical distributions, sourced and used in the exploratory analysis R Markdown document (`02_EXPLORE_DATA/CGFS_est_ouest_exploration_sp_scientific.Rmd`). |

#### Spatial mesh construction and model fitting

| Script | Description |
|---|---|
| `add_mesh_boundary.R`  | Defines a function to incorporate study-area boundaries into spatial mesh construction. The script is sourced before `create_meshes.R`, where the function is called during mesh generation. |
| `create_meshes.R` | Builds candidate spatial meshes for the selected English Channel region(s), using `add_mesh_boundary.R` to incorporate study area boundaries. Mesh configurations vary according to the `cutoff_values`, `max_edge_in` and `max_edge_out` parameters defined in `00_SOURCE.R`. |
| `fit_candidate_models.R` | Fits SPDE-based hierarchical spatiotemporal models across mesh configurations, response variables (biomass and biomass density) and likelihood families selected according to overall species occurrence (lognormal/gamma at 100%; Tweedie/delta otherwise; see **Study area and species** section). Applies a swept-area offset for biomass models and stores successful fits and fitting errors separately. The script uses the mesh configurations generated by `create_meshes.R` and the fixed-effects formula specified in `00_SOURCE.R`. |

#### Model convergence and diagnostics

| Script | Description |
|---|---|
| `check_model_convergence.R` | Examines numerical convergence and model sanity diagnostics for candidate models fitted by `fit_candidate_models.R`. These checks help identify models that may not be suitable for subsequent interpretation or prediction. |
| `extract_converged_models.R` | Uses the convergence diagnostics generated by `check_model_convergence.R` to identify and retain models that pass the convergence checks for subsequent evaluation, diagnostics and prediction. |
| `extract_model_parameters.R`  | Uses the converged models retained by `extract_converged_models.R` to extract and summarise estimated model parameters |
| `compute_dharma_residuals.R` | Generates simulation-based residual diagnostics with `DHARMa` package for the converged models retained by `extract_converged_models.R`. |

#### Goodness-of-fit

| Script | Description |
|---|---|
| `compute_model_caic.R` | Calculates conditional Akaike Information Criterion (cAIC) values and differences in cAIC (ΔcAIC) to compare candidate model fits retained by `extract_converged_models.R`. |
| `compute_R_squared.R` | Calculates the coefficient of determination (R²) from observed and predicted values to summarise their agreement for model fits retained by `extract_converged_models.R`. |

#### Cross-validation and predictive performance

| Script | Description |
|---|---|
| `run_repeated_random_cross_validation.R` | Runs repeated random k-fold cross-validation to evaluate out-of-sample predictive performance. The number of folds (`k_folds`) and repetitions (`n_repeats`) are set in `00_SOURCE.R` (both default to 10). |
| `create_folds_blockCV.R`  | Generates year-specific spatial folds for spatiotemporal block cross-validation and saves the assignments as `.rds` files in `01_DATA/folds_CV/`, subsequently used by `run_block_cross_validation.R`. |
| `run_block_cross_validation.R` | Performs spatiotemporal block cross-validation using the year-specific spatial folds generated by `create_folds_blockCV.R` to evaluate model predictive performance, complementing repeated random cross-validation. |

#### Spatial predictions and mapping

| Script | Description |
|---|---|
| `create_prediction_grid.R` | Generates spatial prediction grids for the selected study region(s), using the grid resolution specified by `res_km` in `00_SOURCE.R` (5 km by default). |
| `predict_converged_models.R` | Generates spatiotemporal predictions from model fits retained by `extract_converged_models.R` and computes bias-corrected abundance indices. |
| `map_model_predictions.R` | Creates maps of spatiotemporal model predictions  using the outputs from `predict_converged_models.R`. |

#### Prediction uncertainty

| Script | Description |
|---|---|
| `compute_simulated_coefficient_variation.R` | Quantifies prediction uncertainty through simulation-based coefficients of variation, expressing relative variability in model predictions. |
| `plot_simulated_coefficient_variation.R` | Generates annual maps of prediction uncertainty using the simulated coefficients of variation computed by `compute_simulated_coefficient_variation.R`. |

**Note:** `create_study_area_shapefile.R`, `create_folds_blockCV.R` and `simulate_candidate_distributions.R` are not directly sourced in the provided `00_SOURCE.R`. They may be invoked by other scripts. The descriptions above summarise their apparent purpose and should be checked against their implementations before publication.



## Cross-species post-processing

The `06_PROCESS_OUTPUTS/` directory contains scripts for post-processing and comparing modelling results across species and model configurations. These analyses are performed separately from the main workflow (`00_SOURCE.R`) and rely on previously generated outputs stored in `05_OUTPUTS/`.

| Script | Description |
|---|---|
| `01_combine_species_model_metrics.R` | Combines model evaluation metrics across species and model configurations. |
| `02_prepare_metrics_comparison_table.R` | Organises the combined metrics into tables for cross-species and model comparisons. |
| `03_plot_model_performance_heatmaps.R` | Generates heatmaps to visualise differences in model performance across species and configurations. |
| `combine_sanity_failures_all_species.R` | Aggregates model convergence and sanity-check failures across species. |
| `map_annual_predictions_selected_models.R` | Generates annual prediction maps for selected models across species. |
| `PCA_model_metrics.R` | Performs principal component analysis (PCA) on model evaluation metrics to explore patterns across species and model configurations. |



## Data availability and reproducibility

The repository provides the R scripts used for data preparation, species distribution modeling, model evaluation and outputs post-processing. The complete contents of `01_DATA/` and `05_OUTPUTS/` are not included.

- **`01_DATA/`** contains input survey datasets, spatial data and intermediate files required to run the analyses.
- **`05_OUTPUTS/`** contains species-specific modeling results, including `.rds` objects generated throughout the workflow.

The code is provided to support methodological transparency. **Full reproducibility requires access to the missing input datasets**, while some post-processing scripts also depend on previously generated model outputs.
