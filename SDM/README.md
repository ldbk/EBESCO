# Species Distribution Modelling in the English Channel

## Overview

This repository contains a workflow written in R (https://www.r-project.org/) for species distribution modeling (SDM) using fisheries-independent survey data from the Channel Ground Fish Survey (CGFS) in the Eastern and Western English Channel.

The workflow uses the **sdmTMB** framework (https://sdmtmb.github.io/sdmTMB/articles/index.html) to investigate spatial and spatiotemporal patterns in fish biomass distribution, while assessing the influence of model configurations, including spatial mesh resolution and likelihood formulation, on model goodness-of-fit, predictive performance, and uncertainty.

The workflow is organised around `00_SOURCE.R`, which sequentially executes the main analysis steps :

1. **Initialisation:**  automatically install missing R packages, update existing packages, and load all required dependencies using `04_MODEL/packages/packages.R`.
2. **Species and region selection:** choose a species and retrieve its eligible study regions.
3. **Data preparation:** load and transform CGFS survey data.
4. **Preliminary diagnostics:** assess spatial autocorrelation using Moran's I and inspect residuals from models without random fields.
5. **Mesh generation:** construct spatial meshes at several resolutions for the selected regions.
6. **Candidate model fitting:** fit `sdmTMB` models across mesh configurations and likelihood formulations.
7. **Convergence assessment:** check numerical diagnostics, retain converged models, and extract parameter estimates.
8. **Residual diagnostics:** calculate simulation-based diagnostics using DHARMa.
9. **Goodness-of-fit:** calculate conditional AIC (cAIC) and R².
10. **Cross-validation:** perform repeated random cross-validation and spatiotemporal blocked cross-validation.
11. **Spatial prediction:** create prediction grids, predict from converged models, and generate biomass density maps and bias-corrected biomass indices.
12. **Uncertainty assessment:** compute simulation-based coefficients of variation and produce uncertainty maps.
13. **Reporting:** render a species-specific HTML report from `04_MODEL/report/sdm_report.Rmd`.

At each step, the outputs generated by the sourced scripts are automatically saved in a species-specific, timestamped directory within `05_OUTPUTS`, following the structure:

```text
05_OUTPUTS/<species_name>/<species_name_date_time>/
```

At the end of the workflow, an R Markdown report (`04_MODEL/report/sdm_report.Rmd`) is rendered into an HTML file, providing a overview of the modeling results, diagnostics, predictions and associated visualisations for the selected species. This report is saved in the same species-specific, timestamped output directory.

Additional scripts in `02_EXPLORE_DATA` support exploratory data analyses, while those in `06_PROCESS_OUTPUTS` are used to post-process, summarise and compare modeling results across species and model configurations.

## Modelling functions

The `04_MODEL/functions/` directory contains :

#### Setup and preliminary analyses

| Script | Description |
|---|---|
| `setup_model_outputs.R` | Initialises the output structure for the selected species. Creates a timestamped run directory under `05_OUTPUTS/<species_name>/` to store the .rds objects generated at each step of the modelling workflow, together with the final HTML report, without overwriting previous runs. |
| `assess_spatial_autocorrelation.R`  | Computes annual Moran's I for observed biomass density using inverse-distance spatial weights, separately for each study region. Compares observed and expected values under the null hypothesis of spatial randomness, assesses statistical significance, and saves the results and diagnostic plots in a species-specific .rds file. |
| `assess_residuals_without_random_fields.R` | Fits preliminary models without spatial random fields and examines the spatial distribution of their residuals to identify potential spatial patterns not accounted for by the fixed-effects structure. |
| `create_study_area_shapefile.R` | Creates a shapefile defining the study area boundaries, used to delineate the inner spatial mesh, define the spatial extent of the prediction grid, and provide a geographic reference for mapping model predictions and other spatial results. |
| `simulate_candidate_distributions.R` | Defines functions for simulating candidate statistical distributions, sourced and used in the exploratory analysis R Markdown document (`02_EXPLORE_DATA/CGFS_est_ouest_exploration_sp_scientific.Rmd`). |

#### Spatial mesh construction and model fitting

| Script | Description |
|---|---|
| `add_mesh_boundary.R`  | Defines a function to incorporate study-area boundaries into spatial mesh construction. The script is sourced before `create_meshes.R`, where the function is called during mesh generation. |
| `create_meshes.R` | Builds candidate spatial meshes for the selected English Channel region(s). Mesh configurations vary according to the `cutoff_values`, `max_edge_in` and `max_edge_out` parameters defined in `00_SOURCE.R`. |
| `fit_candidate_models.R` | Fits candidate `sdmTMB` models for the selected species, region(s) and response variable(s). The script explores the configured mesh resolutions and likelihood formulations using the fixed-effects formula supplied in `00_SOURCE.R`. |

#### Model convergence and diagnostics

| Script | Description |
|---|---|
| `check_model_convergence.R` | Examines numerical convergence and model sanity diagnostics after fitting. These checks help identify candidate models that may not be suitable for subsequent interpretation or prediction. |
| `extract_converged_models.R` | Uses the convergence diagnostics generated by `check_model_convergence.R` to identify and retain models that pass the convergence checks for subsequent evaluation, diagnostics and prediction. |
| `extract_model_parameters.R`  | Uses the converged models retained by `extract_converged_models.R` to extract and summarise estimated model parameters |
| `compute_dharma_residuals.R` | Generates simulation-based residual diagnostics with `DHARMa` package (https://cran.r-project.org/web/packages/DHARMa/vignettes/DHARMa.html) for the converged models retained by extract_converged_models.R. |

#### Goodness-of-fit

| Script | Description |
|---|---|
| `compute_model_caic.R` | Calculates conditional Akaike Information Criterion (cAIC) values and differences in cAIC (ΔcAIC) to compare candidate models retained by `extract_converged_models.R`. |
| `compute_R_squared.R` | Calculates the coefficient of determination (R²) from observed and predicted values to summarise their agreement for models retained by `extract_converged_models.R`. |

#### Cross-validation and predictive performance

| Script | Description |
|---|---|
| `run_repeated_random_cross_validation.R` | Runs repeated random k-fold cross-validation to evaluate out-of-sample predictive performance. The number of folds (`k_folds`) and repetitions (`n_repeats`) are set in `00_SOURCE.R` (both default to 10). |
| `create_folds_blockCV.R`  | Generates year-specific spatial folds for spatiotemporal block cross-validation and saves the assignments as .rds files in `01_DATA/folds_CV/`, subsequently used by `run_block_cross_validation.R`. |
| `run_block_cross_validation.R` | Performs spatiotemporal block cross-validation using the year-specific spatial folds generated by `create_folds_blockCV.R` to evaluate model predictive performance, complementing repeated random cross-validation. |

#### Spatial predictions and mapping

| Script | Description |
|---|---|
| `create_prediction_grid.R` | Generates spatial prediction grids for the selected study region(s), using the grid resolution specified by `res_km` in `00_SOURCE.R` (5 km by default). |
| `predict_converged_models.R` | Generates spatiotemporal predictions from models retained by `extract_converged_models.R` and computes bias-corrected abundance indices. |
| `map_model_predictions.R` | Creates maps of spatiotemporal model predictions  using the outputs from `predict_converged_models.R`. |

#### Prediction uncertainty

| Script | Description |
|---|---|
| `compute_simulated_coefficient_variation.R` | Quantifies prediction uncertainty through simulation-based coefficients of variation, expressing relative variability in model predictions. |
| `plot_simulated_coefficient_variation.R` | Generates annual maps of prediction uncertainty using the simulated coefficients of variation computed by `compute_simulated_coefficient_variation.R`. |

**Note:** `create_study_area_shapefile.R`, `create_folds_blockCV.R` and `simulate_candidate_distributions.R` are not directly sourced in the provided `00_SOURCE.R`. They may be invoked by other scripts. The descriptions above summarise their apparent purpose and should be checked against their implementations before publication.



## Study area and species

The study covers the **Eastern English Channel** and **Western English Channel**. Regions are selected separately for each species using the table `01_DATA/species_criteria_region_10percent.rds`.

Species were selected according to the study objectives and their occurrence in CGFS surveys, using a minimum annual occurrence threshold of 10% per region. The selection procedure is documented in `02_EXPLORE_DATA/species_selection_criteria.R`.

The resulting species-by-region selection criteria are stored in `01_DATA/species_criteria_region_10percent.rds` and automatically loaded in `00_SOURCE.R` to determine whether modelling is performed in the Eastern and/or Western English Channel. 

These predefined settings can be manually overridden by setting `East_English_Channel` and/or `West_English_Channel` to `TRUE` in `00_SOURCE.R`, allowing any species to be modelled in either or both regions, provided the required survey data are available.
