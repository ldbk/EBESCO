# Model outputs

This directory stores the results generated by the species distribution modelling workflow (`00_SOURCE.R`).

For each species, a timestamped directory is automatically created to preserve the outputs of individual modelling runs:

```text
05_OUTPUTS/<species_name>/<species_name_date_time>/
```

Each run contains `.rds` files generated throughout the modelling workflow, including fitted models, diagnostics, model evaluation metrics, spatial predictions and uncertainty estimates. A species-specific HTML report is also generated at the end of the workflow, compiling the results and associated visualisations.

**Data availability:** The complete modelling outputs are not included in this repository. Some scripts in `06_PROCESS_OUTPUTS/` require these previously generated results for cross-species comparisons and post-processing.
